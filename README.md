# KALEIDO — tap, hold, morph

HANABI / LOOMの基本UI・ECHO・HALLを引き継ぐ円形の万華鏡楽器。

## 演奏

タップで音と回転。どこでも時計回り。約320ms長押しすると10〜18°/秒でゆっくり回り続ける。複数指で押しても速度を加算しない。離すと短い余韻を残して停止する。

12時から時計回りに3オクターブの音階を配置。角度で基準音を決め、距離で0 / 12 / 19 / 24半音を加える4層。境界は半径88%・62%・32%。スケールの音数×3の扇形に分割し、音域は従来の低音から高音まで維持。中心半径6%は高い主音。音階と外周の目盛りは画面に固定し、ガラスや三角形が回転しても動かさない。
ROOT / +5TH / +8VEで原音・完全5度上（7半音）・オクターブ上（12半音）の成分を配分。追加の二成分は原音の同じエンベロープ・出力経路に組み込み、独立した多数の長い声を重ねない。

Mirror 3は原音、6/12/Fractalは1/2/3つの短い反射。ガラス・金属・電子音を関連する音色群から選ぶ。新しい反射のまとまりは300ms以上の間隔があるときにだけ生成する。
PLUCK / CHORDの長押しでは、鏡が18°の境界を通過し、450ms以上空いているときに一粒だけ発音。ARPでは8分音符ごとに一つの指を選んで原音・5度上・オクターブ上を巡る。長押しのたびに反射音の束を増殖させない。

ミラー選択ボタンは廃止し、左右ドラッグ（9pxから判定）で鏡の数を3〜12に連続変更。整数間は2種類の鏡像をクロスフェードし、模様の継ぎ目を避ける。なぞっても長押し回転を継続し、なぞった距離が半径の5.5%以上・70ms以上空いたときに短い音を奏でる。左右の動きでは鏡の枚数も変わる。静止中は発音しない。

三角形の頂点は最後に直接弾いたメロディ音・その完全5度上・オクターブ上を、それぞれCelesta / Tines / Glassで鳴らす。辺はWire。採用された直接音だけで基準を更新し、三角形・反射・自動伴奏で基準音が連鎖して上がらない。KEY / SCALE / Octave変更時は基準をリセット。画面の三角形と同じ回転を使って判定し、線をまたぐ速い移動も最大32点で検出。触れた辺・頂点を発光させ、音・発光はループでも再生。指ごとの発音間隔に加えて全体24音/秒・最大18声の制限を維持。

白い曇りガラスの背景と透過する色片。北欧・琥珀・ガーネット・ゴシック・バロック等の12配色。基準音域はC4から。Kaleidoの前版の音域は維持し、他の音色を1オクターブ上げて統一。Octave設定は全音色共通。チェレスタ、ツィンバロン、ハープシコード等をイメージした8つの合成音を追加。中近東寄りのスケール9種、旧Qanun/Santur/Oud音源、未使用の旧地域配色を削除。初期スケールはLydian。民族音楽の厳密な再現ではなく音作りの着想。

HALLの初期値は30。FLOWは静かな伴奏。19音色、KEY / SCALE、オクターブ、ECHO / HALL / VOLUMEは継承。
Bloom / Orbit / Shatterとプリセットは戻していない。

出力を約5.5dB上げ、原音の2.2kHz以上を3dB持ち上げて輪郭を明瞭に。Kaleidoの第2・第3倍音も補強。音量スライダーと既存コンプレッサーは維持。出力の大きなピークだけを滑らかに抑えるソフトリミッターを追加。

## 負荷対策

- 発音は音声時計の55ms先までに制限。それより先の反射は軽量イベントとして保持し、音源ノードを事前大量生成しない。
- 全体で24音/秒を補充するバケット、最大9音の短いバースト。同音色・同音程の55ms以内の重複を抑制。
- 反射・伴奏・長押しの装飾音には3音分の余力を残し、直接触った音と和音を優先。
- 最大18声。装飾音は14声以上で追加せず、声を入れ替える場合は優先度が低い古い声を16msでフェードアウト。
- 一声のオシレーターは直接音で最大5、装飾音で最大2を基本とする。FMの変調器等は別に必要な最小数。
- ガラス片を整数枚では一つ、変化中は隣り合う二つの扇形に描き、鏡面にはそのピクセルを反転複製。発光イベントも最大12件。多数の影ぼかしを廃止。
- 描画は端末のピクセル比2まで。円形の見た目と反射の対称性を維持。

## ループ・停止

REC後の最初の実際の発音から2小節を記録。採用された音だけを記録し、度数、5度/オクターブ、短い音色、回転を再生する。長押しの回転も約100msごとの軽い動きイベントとして保存。ドラッグの枚数変化も保存し、ループ開始時の枚数を復元。KEY / SCALEで再調律。
FLOWは録音しない。PAUSEで休止、CLEARで消去。録音は再読込で消える。
A S D F G H J Kで演奏し、そのまま押し続けると回転。Spaceでループ、Escで停止。
非表示・離脱・音声割り込みでは指の状態、予定発音、音源と回転を停止。Reduced motionでは回転・光の変化を抑える。

## 検証

静的な `dist/` を配信。`python3 -m http.server 8071 --bind 127.0.0.1 --directory dist`

- `node --test tests/kaleido.test.mjs`: 円周の音階配置・距離の4層・回転からの独立性、7/12半音の響き、長押し判定と複数指の速度、発音制限と回復、回転の上限。
- `node tests/browser.cjs`: ドラッグの上下限・連続値・回転継続・発音抑制、タップの音程・複数音色、マウスとタッチの長押し、離した後の停止、ARP、動き込みの録音ループ、ミュート、設定、5画面サイズ。
- `node tests/sound.cjs`: 5度・オクターブを含む19音色の通常音量と音量・残響最大の18音密集時の出音、ピーク、有限値、残響、ステレオ差。
- `node tests/load.cjs layers-10`: CHORDで60回連打、--traceで連続なぞり演奏。変更前は `touch-3`。
- WebMCPはvoice / mirror設定のみ。契約互換スタブで正常・異常入力を確認。ネイティブWebMCPと実機iPhoneでの試聴は未実施。

負荷計測はこのMac上のChrome・390×844・DPR2で実行。実機iPhoneで同じフレーム時間を保証するものではない。計測結果は `artifacts/load-*.json` に保存（Git対象外）。
